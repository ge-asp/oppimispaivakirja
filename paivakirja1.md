# Oppimispäiväkirja: Paikallinen git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet?__

Haastavaa oli käsittää haarautuminen ja niiden välissä navigointi. Sekä mikä on ajan tasalla ja mitä pitää tuoda tai yhdistää, jotta koko projekti olisi ajan tasalla. 

Materiaali oli helppolukuista ja auttoi ymmärtämään suurimman osan käsitteistä.

Suuri apu asioiden ymmärtämisessä oli myös, että minulla on ystävä, joka on alalla ja hän pystyi selittämään minulle käsitteitä auki, mikäli jokin jäi epäselväksi. 
## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git mv <Vanha tiedoston nimi> <Uusi tiedosto nimi> | Vaihtaa tiedoston nimeä |
| git add . | otetaan seuraavaan talletukseen mukaan kaikki uudet ja muuttuneet tiedot |
| git commit -m <kommentti> | Talletetaan muutokset ja jätetään selkeä lyhyt kommentti muutoksista |
| git rm <tiedoston nimi> | Poistaa tiedoston |
| git log | näyttää talletusten historian |
| git revert <hash 7 ensimäistä> | palautettaa aiemman tilan  |
| git switch  -c <uuden haaran nimi> | luo ja vaihtaa uuteen haaraan |
| git switch <haaran nimi> | vaihtaa haaraa |
| git merge <haaran nimi> | yhdistää nimetyn haaran siihen haaraan missä tällä hetkellä on |
